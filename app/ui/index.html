ViBrowse

Lightweight, Low-RAM, Chrome-Compatible Desktop Browser Built with Rust & Tauri v2

Daftar Fitur Lengkap ViBrowse

  • Multi-Tab & Auto Tab Sleeping (RAM Saver) — Tab tidak aktif otomatis di-unload untuk membebaskan RAM, dilengkapi tombol Sleep manual, Pin Tab, dan Reopen Closed Tab (Ctrl+Shift+T).
  • Native Ad-Blocker & Smart Popup Blocker — Memblokir script/iframe iklan di level WebView2 sebelum keluar ke jaringan, menetralisir overlay klik transparan, serta memblokir tab baru pop-under lintas domain dengan opsi pengecualian per situs.
  • Download Manager Terpadu (IDM + Video + Torrent) — Akselerator HTTP/HTTPS hingga 16 koneksi paralel, Video/Media Sniffer otomatis (.mp4/.m3u8), YouTube/1000+ situs via yt-dlp (1-klik install), dan Native Rust BitTorrent/Magnet (librqbit).
  • Mode Incognito / Private Browsing — Profil terisolasi InPrivate tanpa menyimpan cookies, cache, maupun riwayat penjelajahan (Ctrl+Shift+N).
  • Bookmarks, History & Omnibox SQLite Lokal — Penyimpanan cepat SQLite WAL dengan Bookmarks Bar (Ctrl+Shift+B), Quick Access, dan autocomplete cerdas.
  • True Monitor Fullscreen & DevTools — Mendukung fullscreen video penuh satu layar monitor, toggle F11, Chrome DevTools (F12), Zoom, dan seluruh shortcut ala Chrome.
  • Light Mode & Dark Mode + Modern SVG UI — Beralih tema terang/gelap instan dari toolbar atau Settings dengan ikon vektor tajam di segala DPI.

Rendering Engine

WebView2 (Chromium Blink + V8) berbagi runtime OS — 100% kompatibel situs modern, YouTube, WebGL & DevTools tanpa bloatware.

RAM Saver & Tab Sleeping

Tab tidak aktif otomatis di-unload oleh Tokio background worker untuk menghemat RAM tanpa kehilangan URL maupun posisi tab.

Ad & Smart Popup Blocker

Native WebView2 WebResourceRequested filter + pelindung pop-under lintas domain dengan pengecualian per situs.

IDM + Video + BitTorrent

Download Manager 16-koneksi paralel, Video/Media Sniffer, yt-dlp (1000+ situs), dan Native Rust BitTorrent (librqbit).
